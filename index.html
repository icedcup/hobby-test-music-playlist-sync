Robin Music Playlist Sync

A personal, self-hosted tool that copies ListenBrainz recommendations into two playlists in the owner's YouTube Music account. It does not download audio.

  • Daily Jams: up to 50 songs from ListenBrainz Daily Jams.
  • Weekly Jams: up to 100 songs from ListenBrainz Weekly Jams and Weekly Exploration, combined without duplicates.

Why it asks for Google access

The tool uses the YouTube Data API to find the owner's playlists and update only those two managed playlists. Google describes the requested permission as managing the YouTube account; the program uses it only for these playlist operations. Song title and artist searches are sent to YouTube Music to find matches. The sync runs on the owner's server.
